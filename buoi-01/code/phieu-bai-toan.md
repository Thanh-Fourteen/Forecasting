# Phiếu bài toán dự báo

Điền **trước** khi mở dữ liệu. Mỗi ô một đến hai câu, cụ thể tới mức người khác làm lại được.

**Tình huống:** …

| Ô | Câu hỏi | Trả lời |
|---|---|---|
| 1. Quyết định | Ai dùng dự báo, để làm gì, bao lâu làm lại một lần? | |
| 2. Biến mục tiêu | Đo chính xác cái gì, đơn vị nào? | |
| 3. Tầm dự báo | Cần nhìn xa bao nhiêu bước (và mỗi bước dài bao nhiêu)? | |
| 4. Độ chi tiết | Theo sản phẩm / địa điểm / thời gian ở mức nào? Chấm ở mức nào? | |
| 5. Mốc cắt dữ liệu | Lúc ra dự báo đã biết những gì, chưa biết những gì? | |
| 6. Chi phí sai hai chiều | Dự báo **thiếu** 1 đơn vị mất gì? Dự báo **thừa** 1 đơn vị mất gì? Tỷ lệ khoảng bao nhiêu? | |

**Bốn câu hỏi về khả năng dự báo** (một câu mỗi dòng):

- Hiểu các yếu tố tác động tới đâu?
- Có bao nhiêu dữ liệu, bao nhiêu năm?
- Tương lai có giống quá khứ không — có gì sắp thay đổi?
- Công bố dự báo có làm thay đổi chính thứ được dự báo không?
